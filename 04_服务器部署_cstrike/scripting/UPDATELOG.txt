============================================
 HNS Match System - 更新日志 (UPDATELOG)
============================================

【本次更新】LINNA 维护需求

------------------------------------------------
一、回合制比赛规则
  文件: include\hns-match\modes\mode_rounds.inl
------------------------------------------------
1. 新增指令  /linna <回合数> (1-20)
   - 管理员: say /linna 10  => 打满 10 场决胜负
   - 默认打满 10 场

2. 回合换边规则
   - 每局 CT 获胜 => 换边 (T/CT 实体互换重新出生)
   - T 获胜       => 不换边
   - A/B 分数独立累计, 不随换边交换

3. 胜负判定
   - 打满 N 场(默认10)后比分高者胜
   - 打满后 A/B 平局 => 加时 1 场直到分出胜负

4. 比分显示
   - 每回合开头聊天框(绿色[HNS])广播:
      第 X/N 回合 | 当前[CT] X : [TT] X | A队 X : X B队
   - 每回合结束聊天框显示获胜方 + 当前比分
   - 屏幕 HUD 常驻显示回合数与 A/B 比分

------------------------------------------------
二、最Q切刀 (扔投掷物自动切刀) 
  文件: HnsMatchSystem.sma
------------------------------------------------
1. 仅对匪徒(T)生效, CT(警察)不触发
2. 扔出闪光/烟雾弹(无论第几颗), 扔完都强制 Q 切回刀
   - 切刀时重走 deploy 刷新 viewmodel,
     彻底修复"左手残留投掷物模型+刀声"的 T 方渲染 bug
   - (之前尝试过按"最后一颗"才切 / 非最后一颗 redeploy,
     实测仍会左手残留, 故统一改为每次投掷完都强制切刀)
------------------------------------------------
三、服务器无人自动训练模式
  文件: HnsMatchSystem.sma
------------------------------------------------
1. 服务器内无真人玩家(排除bot/HLTV)且无比赛进行中
   => 若当前不是训练模式, 自动切回训练模式
2. 服务器有人进入 => 保持原模式, 不干预("有人就随他")

------------------------------------------------
四、AI报名回合制打满分数
  文件: HnsSignup.sma / include\hns-match\...
------------------------------------------------
1. 独立报名插件(HnsSignup.sma)新增回合制"打满分数"选择
   - 选择回合制模式后, 先选打满分数(5/6/7/8/9/10/11/12分)
   - 管理员在线: 出打满分数选择菜单
   - 管理员离线: 全服投票选打满分数
2. 主插件新增 native: hns_external_set_match_score(iScore)
   - 报名插件开赛前调用, 设置回合制"打满分数"
   - 打满 N 分后比分高者胜, 平局加时
3. 原 /linna <回合数> 手动指令不受影响
