## 1. Обзор проекта

Это полноценная система плагинов для матчевых серверов CS 1.6 HNS (Hide 'n' Seek, прятки).

Основа взята из открытого проекта **OpenHNS** (HnsMatchSystem 2.0.5 и его официальный набор плагинов);
команда GTR встроила в него большой объём собственного кода по всему процессу «**регистрация → формирование команд → выбор режима/карты → старт матча → подведение итогов**»,
создав независимый **собственный матчевый движок GTR**.

## 2. Новая версия vs старая: что изменилось

### 2.1 Проблемы старой версии (корень проблем, устранённых в этом репозитории)

| # | Проблема старой версии | Что реально видели пользователи |
|---|---|---|
| 1 | AI-меню с жёстко зашитым китайским | После переключения `/lang` на английский меню AI-регистрации всё равно остаётся на китайском |
| 2 | Дефектный процесс принудительного старта | После принудительного старта игроков отправляют в наблюдатели и «забывают»: карта/режим не выбираются |
| 3 | Выход на карту через команду `jointeam` | Перехватывается `blockCmd`, игроки застревают в наблюдателях в режиме LOBBY |
| 4 | Участники не помечаются перед стартом | `forceUnmatchedToSpec` в `mix_start()` выкидывает только что вышедших на карту обратно в наблюдатели |
| 5 | Полная потеря состояния при смене карты | После changelevel с выбранной AI-картой регистрация и режим полностью теряются, матч никогда не начинается |
| 6 | Обычная смена карты тоже запускает матч | Админ меняет карту — сервер сам начинает регистрацию и через 2 минуты собирает команды |
| 7 | В спонсорском матче нет записи спонсора | Спонсорский матч запущен, но никто не может сообщить системе, «кто спонсор» |
| 8 | 7-й пункт меню mix некорректен | 7-й пункт (режим HNS) «не нажимается»: в языковой строке нет `^n`, пункт выглядит мёртвым |
| 9 | Полоса счётчика регистрации | В чате/HUD отображается `012345[6]78910`, пользователи просили убрать её |
| 10 | Меню регистрации закрывается после одного клика | Хочется продолжать операции в меню, но оно само закрывается |

### 2.2 Соответствующие улучшения в новой версии (Huaxue Edition v1.19)

| # | Улучшение | Как реализовано |
|---|---|---|
| 1 | **AI-меню полностью локализовано** | Всё через `HnsLang_Get(id, key)`, поддержка 4 языков (упрощ. китайский / традиц. китайский / английский / русский), синхронизация с `/lang` в реальном времени |
| 2 | **Переработан процесс регистрации** | Конечный автомат `SIGNUP_STATE`: регистрация → сбор команд (все в наблюдателях + по 1 игроку в секунду на карту) → выбор режима/карты → старт матча |
| 3 | **Безопасный выход на карту через ReAPI** | Вместо `jointeam` используется `rg_set_user_team` (ReAPI); разрешено в LOBBY/TRAINING, исключены застревания в наблюдателях |
| 4 | **Предварительная пометка участников при внешнем старте** | Новый native `hns_begin_external_match` до старта помечает T/CT как участников — устраняет вторую корневую причину «все возвращаются в наблюдатели в момент старта» |
| 5 | **Восстановление PDS между картами** | После выбора карты `PDS_SetCell("ai_pending_start",1)`, при возврате после смены карты матч автоматически продолжается через 5 секунд (`taskPendingResume`) |
| 6 | **Обычная смена карты больше не запускает матч** | Смена карты вне режима pending: регистрация очищается, сервер в ожидании, старт запускает админ вручную |
| 7 | **Запись спонсора в спонсорском матче** | После выбора карты первый онлайн-VIP/админ вводит имя спонсора в чат; тайм-аут 30 секунд или `/取消` для пропуска |
| 8 | **Фиксированная нумерация меню mix** | 7-й пункт всегда ICGB (серый и недоступный без спонсорского матча), 8-й пункт всегда меню администратора |
| 9 | **Убран интерфейс полосы счёта** | Удалён `buildSignupBar()`, в HUD показывается только `报名: n/12` |
| 10 | **Меню не закрывается после выбора** | После действия в меню регистрации возврат в главное меню для непрерывной работы |
| 11 | **Определение победы по логической команде** | Новый native `hns_get_player_match_team`; при расчёте wintime очки начисляются нужной команде (v1.19) |
| 12 | **Ограничение прав в меню** | Размер команды / повторное разделение / принудительный старт видны и доступны только VIP/админу (v1.19) |
| 13 | **Единственный режим состояния матча** | AI и MatchSystem используют один общий режим; после смены карты он восстанавливается вместе со всем остальным — без расхождений (v1.19) |

## 3. Особенности Huaxue Edition v1.19

- 🤖 **Система AI-регистрации v1.19**: `/signup` — регистрация в один клик, сбор и формирование команд, развлекательные/спонсорские матчи, голосование за режим и карту,
  принудительный старт (можно тестировать с 1 игроком), продолжение матча после смены карты, счётчик регистрации на HUD.
- 🎨 **Система скинов (MySQL)**: игроки настраивают собственные скины, покупка за монеты / аренда / постоянное улучшение,
  случайные звуки смерти, управление через админ-меню `/cpm`.
- 💳 **Спонсорство / система монет ICGB**: в спонсорских матчах спонсор записывается автоматически, монеты связаны со скинами.
- 🗂 **Межкартовая персистентность (PDS)**: при смене карты состояние матча не теряется, после выбора карты AI матч автоматически восстанавливается.
- 🌐 **Локализация на 4 языках**: упрощ. / традиц. китайский / English / Русский, единое меню AI и матча.
- 🧠 **AI-боты для матчей**: можно протестировать матч даже с 1 игроком, без застревания в наблюдателях.
- 🛡 **Стабильный порядок загрузки**: В `plugins.ini` порядок уже выстроен: HnsLanguage → PDS → Sponsor → MatchSystem → … → AISignup → Skin.
- 🎯 **Исправление определения победы**: при расчёте wintime очки начисляются по логической матчевой команде; при смене сторон/карты очки больше не начисляются не тем игрокам.
- 🔐 **Ограничение прав**: управляющие действия (размер команды / повторное разделение / принудительный старт) видны и доступны только VIP/админу.

## 6. Быстрое развертывание

1. Перейдите в раздел **Release** и скачайте последний пакет развёртывания **Huaxue Edition** `gtr_deploy_package_v1.19.zip`
2. Распакуйте `addons/` и скопируйте поверх каталога `cstrike/` на сервере
3. Настройте MySQL по `部署说明.txt` (для базы скинов при первом запуске нужно создать таблицы)
4. Перезапустите сервер / смените карту, проверьте в консоли `amxx plugins` — не должно быть failed
5. После входа игрока заголовок главного меню `/menu` должен отображать **Hide'And'Seek**

> Подробное развёртывание — в `10_交接与文档/` и в описании Release.

## 8. Авторские права

- **Плагины экосистемы OpenHNS** (HnsMatchSystem / Bans / Maps / Stats и др.): права принадлежат авторам
  (OpenHNS / Garey / Cultura и др.), открытая лицензия типа MIT.
- **Собственные расширения GTR** (AI-регистрация, спонсорство, управление скинами, межкартовая персистентность, локализация и др.): разработаны на основе указанного выше движка.
- **Пакеты сторонних плагинов** (SEM / rtv / FreshBans и др.): права принадлежат соответствующим авторам, источник — российский сайт dream-x.ru.
